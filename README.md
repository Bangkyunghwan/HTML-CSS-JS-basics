# 🎨 프론트엔드 기초 스터디 (HTML/CSS/JS)

HTML, CSS, JavaScript의 핵심 기초 문법을 학습하고, 간단한 웹페이지 클론 코딩을 연습한 내용을 기록하는 레포지토리입니다.

## 📚 학습 내용

* **HTML:** 시맨틱 태그, 폼(form) 작성
* **CSS:** Flexbox/Grid 레이아웃, 미디어 쿼리 (반응형 웹)
* **JavaScript:** DOM 조작, 이벤트 리스너, `fetch` 비동기 통신

<br>

## 🚀 클론 코딩

학습한 내용을 바탕으로 간단한 웹사이트의 UI 클론 코딩 (엔비디아 웹 페이지)
